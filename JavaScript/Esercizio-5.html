Pokèdex

Vogliamo creare una funzione asincrona che cerca i dati di un Pokémon usando un'API pubblica e gratuita chiamata PokeAPI. L'URL base per cercare un Pokémon per nome o per ID è questo: [https://pokeapi.co/api/v2/pokemon/](https://pokeapi.co/api/v2/pokemon/) (seguito dal nome o dall'ID).

Aprire la console del browser con F12 per vedere l'output del codice
